# 구현 및 검증 기록

기준: 2026-11-05 (한국 시간). 검증 환경은 Linux 클라우드이며 Windows 명령은 이식 가능한 PowerShell 형태로 문서화했지만 Windows OS에서 직접 실행하지는 않았습니다.

## 현재 확인한 것

- React/Vite production 빌드 성공. 화면 기능별 코드 분할을 적용했습니다.
- Vitest 서버 테스트: 실제 Miniflare D1 엔진을 사용하고 외부 LLM HTTP만 모의 응답으로 대체합니다.
- Playwright Chromium 브라우저 테스트: 문답·돌아보기·중단·새로고침, 편집 확인 취소·재생성, 선언 기반 탐색·복귀, 모바일 지도 빈 상태, Markdown 공격 비실행·코드 복사를 확인합니다. 이 테스트의 API는 모의 응답입니다.
- 실제 Wrangler Pages 로컬 서버의 화면 HTTP 200, D1 세션 생성/읽기/삭제, 키 누락 시 안전한 503, 입력 보존, 생성 잠금 해제를 별도로 확인했습니다.
- 로컬 D1 migration 0001 적용 성공. 원격 DB에는 적용하지 않았습니다.
- 실제 Pages 화면을 데스크톱 1440px 및 모바일 390px에서 확인했습니다.

정확한 최종 테스트 수와 검토 결과는 아래 최종 검증 항목에 기록합니다.

## 배포 전에 필요한 것

1. OpenRouter 비밀값과 현재 제공되는 고정 무료 모델 ID. Nemotron 3 Ultra의 정확한 무료 ID는 확인되지 않았으며 지어낸 기본값을 넣지 않았습니다.
2. 해당 모델의 구조 JSON·검색 plugin·annotations·무료 데이터 정책·현재 한도 확인. 공식 OpenRouter/Cloudflare 문서는 이 환경에서 HTTP 403으로 차단되어 최신 요금·한도 숫자를 독립 검증하지 못했습니다.
3. 실제 Cloudflare Pages 이름과 연결 브랜치, 실제 D1 ID/DB 바인딩/원격 migration.
4. Production·Preview·대체 호스트의 Access 보호와 issuer/audience/허용 이메일. 서버 인증은 설정 누락 시 거부합니다.
5. 실계정으로 문답 품질·중립성과 실제 검색 출처, 운영 D1 복구를 확인해야 합니다.

대화 기록·키·운영 데이터는 Git에 넣지 않았습니다. 이후 사용자 요청으로 구현을 GitHub socratic-explorer-preview 브랜치에 push했습니다. main은 기존 템플릿 상태이며 Cloudflare 배포 URL·운영 적용·새 환경 게시 성공은 확인하지 못했습니다. 최신 진행 상태는 루트 HANDOFF.md를 참고하세요.

## 구현 결정

- Cloud skill의 실행 보조 shell 파일이 로컬에 없어 동일 역할의 로컬 진행 ledger를 직접 관리했습니다. 위험: 진행 기록 누락 가능성으로 Git과 테스트 결과를 함께 확인합니다.
- Miniflare로 실제 로컬 D1을 검증하고 모델 HTTP만 대체했습니다. 비용: 실제 원격 모델·배포 확인은 별도로 필요합니다.
- 호환성 날짜는 설치 가능한 Cloudflare 런타임이 지원하는 2026-07-30을 사용했습니다. 최신 날짜 기능에 의존하지 않습니다.
- 관련 API·화면·인증이 함께 빌드되는 구조라 구현 커밋은 기능 집합 단위로 묶었습니다. 비용: 계획의 작업별 작은 커밋보다 검토 단위가 큽니다.
- 호출 실패를 자동 재시도하지 않습니다. 사용자가 재시도를 선택해 무료 호출과 검색 비용이 조용히 소모되지 않게 합니다.

## 최종 검증

서버 36/36, 브라우저 7/7 통과 (skip 없음), production build 성공, git diff --check 통과. 독립 전체 코드 검토에서 발견한 다음 항목을 실패 테스트로 재현한 뒤 수정했습니다.

- 세션 UPDATE를 대상 행으로 제한해 다른 대화의 제목·상태·생성 잠금이 함께 바뀌지 않도록 수정.
- 후속 메시지가 없어도 연관 탐색이 있으면 질문 재생성 전에 삭제 영향을 확인하고 확인한 revision 사용.
- 자료 출처 교체·질문 결과·실행권 해제를 하나의 조건부 D1 batch로 묶어 중단된 시도의 출처가 다음 결과에 섞이지 않도록 수정.
- 지도 snapshot의 revision을 클라이언트 변경 요청에 포함하고, 오래된 수정이 삭제된 관계를 복원하지 못하도록 수정.
- 탐색을 시작한 탭에서도 실제 저장된 활성 단계를 보수적으로 조회해 진행 상태 표시. 낮은 revision의 늦은 조회 응답은 무시.

추가 실제 HTTP 확인: 로컬 Pages/D1 지도 revision 4→5→6, 관계 생성·삭제 및 오래된 revision 수정 409 거부. npm ci 재설치와 local migration 재실행(no migrations) 성공. 실제 OpenRouter·Windows OS·원격 배포는 미실행입니다.

검토에서 보류한 실모델 품질·실검색 동작/요금·운영 Access 설정은 자격증명과 배포 환경이 필요하므로 코드 결함으로 취급하지 않았습니다. 위험은 실제 사용 전 별도 검증이 필요하다는 점입니다. 진행 상태 문제는 과제의 핵심 표시 요구에 영향을 주므로 중요 항목으로 올려 수정했습니다. 미해결 검토 지적은 없습니다.

클라우드 환경의 설치·시작 초안도 새 앱에 맞게 저장했습니다. 기존 api.cloudflare.com 규칙을 보존하고 openrouter.ai 및 developers.cloudflare.com을 추가했으며 OpenRouter secret 요구사항과 LLM_MODEL 이름을 등록했습니다. 초안 저장은 실행 환경에 적용하거나 게시한 것이 아닙니다. 환경 설정에서 검토·저장 후 환경 게시가 필요하며, 이 게시와 Cloudflare 앱 배포는 별개입니다.
